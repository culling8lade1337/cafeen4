# Caféen4

One-page website for Caféen4, a café by Peblinge Lake in Copenhagen.

- Floating top-six dishes that react to scroll and pointer
- Menu with search and category filters (Danish / English switch)
- Table reservation form (preview only, not yet connected to an inbox)
- Opening hours with live "open now" status, illustrated map, FAQ

Everything is in a single file, `index.html`. Open it in a browser, or enable GitHub Pages (Settings, Pages, branch `main`, folder `/`) to host it.

Address: Peblinge Dossering 4, kld, TH, 2200 København
